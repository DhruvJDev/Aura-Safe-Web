# Aura Safe - Women's Safety App Landing Page

A professional, modern landing page for the Aura Safe women's safety application built with React and Vite.

**Aura Safe** is a modern, user-friendly women safety app that provides immediate emergency assistance and support. The app combines multiple features to ensure quick response in critical situations and maintains a network of trusted contacts.

## Features

✨ **Modern Design**
- Elegant rose/pink color theme inspired by the app icon
- Smooth animations and transitions throughout
- Professional and responsive layout
- Circular logo badge in header for professional appearance

🎯 **Key Sections**
- Hero section with compelling women's safety value proposition
- Features showcase with safety-focused icons and descriptions
- Download section for iOS and Android apps
- Statistics highlighting user trust and reliability
- Professional footer with navigation links

**Safety Features Highlighted:**
- 🔴 One-Touch Emergency SOS
- 👥 Trusted Contacts Network
- 📍 Live Location Sharing
- 🔔 Real-Time Alerts

🎨 **Animations**
- Fade-in and slide-in animations on page load
- Hover effects on interactive elements
- Glowing and pulsing animations for visual interest
- Smooth scroll navigation

📱 **Responsive Design**
- Mobile-friendly layout
- Optimized for all screen sizes
- Touch-friendly buttons and navigation

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Navigate to the project directory:
```bash
cd /Users/dhruvjindal/Work/Git_repo/Aura-Safe-Web
```

2. Install dependencies:
```bash
npm install
```

### Running the Development Server

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:3000`

### Building for Production

Create an optimized production build:
```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

Preview the production build locally:
```bash
npm run preview
```

## Customization

### Colors
The primary color scheme uses rose/pink tones (`#d97ba8`, `#e91e63`). To change colors, modify the CSS gradients in `src/styles.css`.

### Content
Update app descriptions, features, and statistics in the component files within `src/components/`.

### Images
Replace `app_icon.png` with a different image if needed. The icon is featured in multiple sections with animations.
